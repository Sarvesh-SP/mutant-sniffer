# Mutant Sniffer Chrome Extension

This is a Chrome extension that detects and allows you to download `.m3u8` video streams as MP4 files.

## Features
- Detects `.m3u8` streams from websites.
- Provides an option to download `.m3u8` streams as MP4 videos.

## How to Install Locally

### Prerequisites
- **Google Chrome** (or any Chromium-based browser like Brave, Vivaldi).
- Basic knowledge of how to install extensions manually.

### Steps to Install the Extension

1. **Download the Extension Files**:
   - Go to the [Releases page](https://github.com/Sarvesh-SP/mutant-sniffer/releases).
   - Download the latest `.zip` file for the extension.

2. **Extract the Files**:
   - Extract the `.zip` file to a folder on your computer.

3. **Load the Extension in Chrome**:
   - Open Google Chrome and go to `chrome://extensions/`.
   - Enable **Developer mode** (toggle switch in the top right).
   - Click on **"Load unpacked"** and select the folder where you extracted the extension files.
   - The extension should now be installed and visible in the Chrome extensions bar.

4. **Use the Extension**:
   - After installation, you should see the Mutant Sniffer icon in the Chrome toolbar.
   - Click on the extension icon to view and download `.m3u8` streams as MP4.

### How to Use

1. Navigate to a webpage with a `.m3u8` video stream.
2. Click on the Mutant Sniffer extension icon in the toolbar.
3. If a `.m3u8` stream is detected, the URL will appear in the extension popup.
4. You can then copy the URL or click the **"Download MP4"** button to start the download process.
